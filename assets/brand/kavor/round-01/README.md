# Kavor logo concepts — round 01

This folder is the concept checkpoint for the Kavor HRM identity. It intentionally contains black-and-white directions only. Colour, app icons, favicons, final lockups and usage guidelines should be produced after one direction is selected.

## Overview

- `kavor-logo-concepts.png` — the presentation sheet to review first.
- `kavor-logo-concepts.svg` — scalable source for the presentation sheet.
- `preview-tests.html` / `preview-tests.png` — scale, one-colour, reversed, background, rotation and context tests.
- `BRIEF.md` — working brief, assumptions and concept longlist.
- `concept-*-symbol.svg` — standalone app-icon candidates.
- `concept-*-lockup.svg` — horizontal symbol + custom outlined `KAVOR` wordmark.

## Directions

### A — Core K (recommended)

A bold K holds a circular negative-space core. The circle represents people and culture at the centre of the system. It is the strongest balance of memorability, compactness and enterprise confidence.

**Risk:** the central dot may be read simply as punctuation until the brand story is learned.

### B — Relay Loop

Two mirrored hooks pass work from one side to the other, expressing connected employee journeys and approval handoffs without using literal HR symbols.

**Risk:** the abstract form needs more exposure before users associate it with Kavor.

### C — Roster K

Three independent modules align into one K, representing distinct people and teams becoming one organised workforce.

**Risk:** modular K marks are common in technology, so final colour and motion would need to increase ownership.

## Verification

- SVG structure: vector-only; no live text, raster images, filters or gradients.
- Symbol audit: A 99/100, B 100/100, C 99/100. The informational horizontal offset on A and C is intentional optical centring for the asymmetric K silhouette.
- Horizontal lockup audit: 100/100 for all three directions.
- Visual review: checked at 16, 32, 64, 96, 128 and 256 px; one-colour black/white; brand background `#065F46`; mirror and 180° rotation; browser-tab, app-icon, avatar and header contexts.

## Next checkpoint

Choose A, B or C (or specify which elements to combine). The selected direction can then be refined into a full kit using the current product palette: emerald `#065F46`, mint `#A7F3D0` and cream `#FFF8E7`.

Trademark availability has not been checked. Before launch, run a professional trademark and reverse-image search in the intended markets.
